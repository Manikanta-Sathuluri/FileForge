# Contributing

1. Create a branch.
2. Make the smallest focused change possible.
3. Add or update tests.
4. Run `pytest`.
5. Run `pip-audit`.
6. Build the Windows executable with `build.bat`.
7. Open a pull request with a clear description.

Do not commit passwords, API keys, certificates, private keys, personal images, build artifacts, or generated executables unless a release process explicitly requires them.
